How to Play

Goal

Get your symbols in a row — horizontal, vertical, or diagonal — and reach the win length for the chosen board size before your opponent.

Board Sizes & Win Length

  • 3×3 — get 3 in a row (classic).
  • 4×4 — choose 3 or 4 in a row.
  • 5×5 — choose 4 or 5 in a row.
  • 6×6 — 4 or 5 in a row.
  • 7×7 — 4, 5 or 6 in a row.
  • 8×8 — 5 or more in a row.
  • 9×9 — 5 or 6 in a row.
  • 10×10 — 5 or more in a row.

Game Modes

  • Local Solo — vs AI with 5 difficulty levels.
  • Local Multiplayer — pass-and-play on one device.
  • Join with Code — same-LAN multiplayer. Run the Python server, share the 4-digit code, both devices connect.

AI Difficulty

  • Easy — random moves.
  • Medium — basic win/block logic.
  • Hard — strategic with lookahead.
  • Expert — deeper search with heuristics.
  • Impossible — full minimax with alpha-beta. Unbeatable on 3×3. On larger boards it uses bounded depth search and is strong but not literally unbeatable.

R Coins

Earn coins by winning matches and completing missions. Smaller rewards for draws. Use coins to unlock arenas, symbols and avatar frames. Redeem codes for bonus coins.

Redeem Codes

  • RABBi — Unlimited R Coins mode (local profile only).
  • WELCOME100 — 100 R Coins (once).
  • ARENA500 — 500 R Coins (once).
  • STARTER250 — 250 R Coins (once).

Codes are case-insensitive. RABBi must be spelled exactly. Codes are not secure against someone editing their browser data — that's fine for an offline single-player game.

LAN Multiplayer Setup

  1. Run python app.py on the host computer.
  2. Find the host's local IP (e.g. 192.168.1.10).
  3. On the other device, set the server URL to ws://192.168.1.10:8000 and join with the 4-digit code.
  4. Both devices must be on the same Wi-Fi/LAN. This is NOT cross-internet multiplayer.
